**3. Create PluginManager.cs** (`src/Audex/Audio/PluginManager.cs`):
Static class with:
- `private static readonly Dictionary<string, int> _loadedPlugins` — tracks loaded plugin handles
- `private static readonly Dictionary<string, string[]> _pluginFormats` mapping plugin DLL name to extensions:
  - `"bass_aac"` -> `[".aac", ".m4a"]`
  - `"basswma"` -> `[".wma"]`
  - `"bassopus"` -> `[".opus"]`
- Core BASS-supported extensions (no plugin needed): `[".wav", ".mp3", ".flac", ".aiff", ".aif", ".ogg"]`
- Module format extensions: `[".mod", ".xm", ".it", ".s3m"]`
- `LoadPlugins(string dllDirectory)`: For each entry in _pluginFormats, check if DLL file exists at `Path.Combine(dllDirectory, pluginName + ".dll")`. If exists, call `Bass.PluginLoad(absolutePath)`. Log success/failure to Logger.Info/Logger.Error. Store handle in _loadedPlugins on success.
- `IsFormatSupported(string extension)`: Returns true if extension is in core list, module list, or if the required plugin is in _loadedPlugins.
- `GetUnsupportedReason(string extension)`: Returns null if supported. Returns descriptive string if not, e.g., "OPUS plugin not found" if bassopus not loaded, or "Unsupported format" for completely unknown extensions.
- `IsModuleFormat(string extension)`: Returns true for .mod, .xm, .it, .s3m. Used by AudioPlayer and WaveformGenerator to choose MusicLoad vs CreateStream path.
- All extension comparisons case-insensitive (use `.ToLowerInvariant()`).

For module formats, the stream creation must use `Bass.MusicLoad` instead of `Bass.CreateStream`:
- At the start of the method, after GCHandle.Alloc, add a branch:
  ```csharp
  if (isModuleFormat)
  {
      waveStream = Bass.MusicLoad(false, audioData, 0, audioData.Length,
          BassFlags.Decode | BassFlags.Float | BassFlags.MusicPrescan, 0);
  }
  else
  {
      waveStream = Bass.CreateStream(ptr, 0, audioData.Length, BassFlags.Decode | BassFlags.Float);
  }
  ```
  Note: For module format, GCHandle is still needed for the duration of the Generate call because we're reading PCM data from the stream. MusicLoad copies the module data but the stream operations still need the original memory. Actually, check: MusicLoad copies data internally, so the GCHandle is NOT needed for module formats. But since we already allocated it and it's freed at the end, it's harmless to keep the code uniform. Leave GCHandle allocation for both paths for simplicity.

- In the cleanup at the end and in catch blocks, use the correct free function:
  ```csharp
  if (isModuleFormat)
      Bass.MusicFree(waveStream);
  else
      Bass.StreamFree(waveStream);
  ```
  This applies to all three places waveStream is freed: the early returns, the `done:` path, and the `catch` block.

For the FFT section within the decode loop, per user decision "module formats: simpler mono-color waveform only (no frequency coloring)":
- Wrap the FFT block in `if (!isModuleFormat)`:

**2. Update AudioHeaderParserFactory.Parse()** — Add module format routing:

In the switch expression, add cases for module formats:
```csharp
".mod" => CreateUnsupportedFormat(fileName, fileSize, "MOD"),
".xm" => CreateUnsupportedFormat(fileName, fileSize, "XM"),
".it" => CreateUnsupportedFormat(fileName, fileSize, "IT"),
".s3m" => CreateUnsupportedFormat(fileName, fileSize, "S3M"),
```
These use CreateUnsupportedFormat (same as existing AIFF/OGG) because we delegate to BASS for actual metadata — the header parsers are only used for bit depth, which is not meaningful for module formats. The ParseSucceeded=false flag is fine because AudioPreviewHandler.DoPreviewInternal already overrides with BASS-derived values.

Also in DetectFormatFromStream, add magic bytes detection for common module signatures:
- MOD: bytes at offset 1080 = "M.K." or "4CHN" or "6CHN" or "8CHN" or "FLT4" (classic Amiga MOD signature)
- XM: starts with "Extended Module:" (0x45 0x78 0x74 0x65...)
- IT: starts with "IMPM" (0x49 0x4D 0x50 0x4D)
- S3M: byte at offset 44 = 0x1A, bytes at offset 0x2C = "SCRM"

Keep it simple — if the extension is present (which it will be from Explorer), magic bytes detection is only a fallback for "Unknown" filenames. Add the common ones and skip obscure variants.

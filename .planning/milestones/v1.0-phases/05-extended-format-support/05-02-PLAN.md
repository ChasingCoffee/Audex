**1. Create MusicKeyNormalizer.cs** (`src/Audex/Audio/MusicKeyNormalizer.cs`):

Static class that normalizes musical key notation to standard form (Am, C#m, F, etc.):

- `private static readonly Dictionary<string, string> CamelotMap` -- maps "1A"-"12A", "1B"-"12B" to standard keys. Full mapping from research:
  1A=Abm, 1B=B, 2A=Ebm, 2B=F#, 3A=Bbm, 3B=Db, 4A=Fm, 4B=Ab, 5A=Cm, 5B=Eb, 6A=Gm, 6B=Bb, 7A=Dm, 7B=F, 8A=Am, 8B=C, 9A=Em, 9B=G, 10A=Bm, 10B=D, 11A=F#m, 11B=A, 12A=C#m, 12B=E

- `private static readonly Dictionary<string, string> OpenKeyMap` -- maps "1d"-"12d", "1m"-"12m" to standard keys. Full mapping from research:
  1d=C, 1m=Am, 2d=G, 2m=Em, 3d=D, 3m=Bm, 4d=A, 4m=F#m, 5d=E, 5m=C#m, 6d=B, 6m=Abm, 7d=F#, 7m=Ebm, 8d=Db, 8m=Bbm, 9d=Ab, 9m=Fm, 10d=Eb, 10m=Cm, 11d=Bb, 11m=Gm, 12d=F, 12m=Dm

- `public static string? Normalize(string? raw)`:
  1. Return null if null/whitespace
  2. Trim the input
  3. Check Camelot (case-insensitive: `trimmed.ToUpperInvariant()`)
  4. Check Open Key (case-insensitive: `trimmed.ToLowerInvariant()`)
  5. Check if already standard notation via `IsStandardNotation()`
  6. Try text variations: regex `^([A-Ga-g][#b]?)\s*(minor|min|m)$` -> append "m", `^([A-Ga-g][#b]?)\s*(major|maj)?$` -> root only
  7. Return as-is if unrecognized (better to show raw than nothing)

- `private static bool IsStandardNotation(string s)`: Returns true for valid keys like "C", "C#", "Db", "Am", "F#m", "Bbm", etc. Pattern: root note (A-G) + optional sharp/flat (# or b) + optional "m" for minor. Validate against the 24 known keys.

Add `public static MusicInfo ReadMusicInfo(byte[] data, string fileName)`:
- Create ByteArrayFileAbstraction and TagLib.File.Create (same pattern as ReadTags)
- Read from all tag types in priority order:

  **BPM sources (first non-null wins):**
  1. ID3v2 TBPM frame via `GetId3v2TextFrame(id3v2, "TBPM")` -- This covers Traktor (writes standard TBPM) and Serato (writes standard TBPM)
  2. Vorbis Comment "BPM" field
  3. APE "BPM" field
  4. Serato Autotags GEOB frame (parse BPM from binary -- see research Pattern 3) -- Fallback for files where Serato analysis exists but standard TBPM was not written

  **Key sources (first non-null wins):**
  1. ID3v2 TKEY frame via `GetId3v2TextFrame(id3v2, "TKEY")` -- This covers Traktor (writes standard TKEY) and rekordbox (writes TKEY when enabled in settings)
  2. Vorbis Comment "INITIALKEY" field
  3. APE "INITIALKEY" field

  **DJ software coverage note (per user decision "Read Serato, Traktor, and rekordbox custom BPM/key tags as fallbacks"):**
  - Traktor: Writes standard TBPM and TKEY frames -- covered by sources 1 above. No need to parse Traktor PRIV frame (proprietary, undocumented binary).
  - Rekordbox: Writes TKEY to standard ID3 tags (covered by key source 1). Does NOT write TBPM -- this is a known rekordbox limitation. Phase 6 BPM detection will fill this gap.
  - Serato: Writes standard TBPM/TKEY AND Serato Autotags GEOB. Standard tags covered by source 1; GEOB is fallback for files without standard TBPM.

  **Conflict resolution for BPM ("most precise wins" per user decision):**
  - Collect ALL non-null BPM values from all sources
  - Parse each as double
  - The value with the most decimal places wins (e.g., "119.97" beats "120")
  - If equal precision, first source wins
  - Round winning value to nearest integer for display

  **Normalize key:** Call `MusicKeyNormalizer.Normalize(rawKey)` before returning.

  **Return:** `new MusicInfo(bpmInt, normalizedKey)`

Add helper methods:
- `private static string? GetId3v2TextFrame(TagLib.Id3v2.Tag tag, string frameId)` -- get text from ID3v2 frame (see research code example)

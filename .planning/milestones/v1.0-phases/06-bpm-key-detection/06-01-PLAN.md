               public bool BpmFailed { get; set; }

    1. Create `src/Audex/Audio/KeyDetector.cs` — Krumhansl-Schmuckler key detection:
       - Static class `KeyDetector` in namespace `Audex.Audio`
       - Private static readonly `double[] MajorProfile` = { 6.35, 2.23, 3.48, 2.33, 4.38, 4.09, 2.52, 5.19, 2.39, 3.66, 2.29, 2.88 } (Krumhansl 1990)
       - Private static readonly `double[] MinorProfile` = { 6.33, 2.68, 3.52, 5.38, 2.60, 3.53, 2.54, 4.75, 3.98, 2.69, 3.34, 3.17 }
       - Private static readonly `string[] MajorKeys` = { "C", "Db", "D", "Eb", "E", "F", "F#", "G", "Ab", "A", "Bb", "B" } — standard enharmonic per user decision
       - Private static readonly `string[] MinorKeys` = { "Cm", "C#m", "Dm", "Ebm", "Em", "Fm", "F#m", "Gm", "Abm", "Am", "Bbm", "Bm" }
       - Public static method `(string key, float confidence) DetectKeyFromChromagram(double[] chroma)`:
         - Normalize chromagram to sum=1; if sum < 1e-10 return ("--", 0f) where -- is an em dash
         - For each root (0-11), compute PearsonCorrelation against RotateProfile(MajorProfile, root) and RotateProfile(MinorProfile, root)
         - Track bestCorr and bestKey across all 24 correlations
         - Convert correlation to confidence: `Math.Max(0, Math.Min(1, (bestCorr + 1.0) / 2.0))`
         - Return (bestKey, confidence)
       - Private static `double PearsonCorrelation(double[] x, double[] y)`: standard Pearson r for arrays of length 12
       - Private static `double[] RotateProfile(double[] profile, int semitones)`: rotate array right by semitones (new array, index i = profile[(i - semitones + 12) % 12])
       - Public static `int FreqToPitchClass(double freqHz)`: returns 0-11 (C=0) using MIDI formula `69 + 12 * log2(freq/440)`, mod 12, or -1 if freq <= 0

    2. Create `src/Audex/Audio/BpmKeyAnalyzer.cs` — orchestrates BPM + key detection:
       - Static class `BpmKeyAnalyzer` in namespace `Audex.Audio`
       - Using ManagedBass, ManagedBass.Fx, System.Runtime.InteropServices, System.Threading
       - Public static method `AnalysisResult Analyze(byte[] audioData, CancellationToken ct, Action<float> onProgress, double maxSeconds = 300.0)`:
         - Pin audioData with GCHandle.Alloc(Pinned)
         - Create BASS decode stream: `Bass.CreateStream(ptr, 0, audioData.Length, BassFlags.Decode | BassFlags.Float)`
         - If stream == 0, return failure result
         - Get total duration via ChannelBytes2Seconds; clamp to maxSeconds
         - **BPM phase (0-50% progress):**
           - Call `BassFx.BPMDecodeGet(stream, 0.0, endSec, 0, BassFlags.Default, progressCallback, IntPtr.Zero)` where progressCallback maps percent to `onProgress(pct * 0.5f)`
           - Check ct.IsCancellationRequested inside progressCallback -- if cancelled, just return (BPMDecodeGet will complete but result is discarded)
           - If bpm > 0: round to int, assign confidence (0.92 for 60-200 range, 0.70 for extremes 45-60 or 200-230)
           - If bpm <= 0 or -1: mark BpmFailed = true
         - Free the BPM stream: `Bass.StreamFree(stream); stream = 0`
         - If ct.IsCancellationRequested, free handle, return null (caller handles)
         - **Key phase (50-100% progress):**
           - Create a NEW decode stream from same pinned data: `Bass.CreateStream(ptr, 0, audioData.Length, BassFlags.Decode | BassFlags.Float)`
           - Get ChannelInfo for sampleRate
           - Pre-compute binToPitchClass[2048] mapping: for each bin 1..2047, freq = bin * sampleRate / 4096; if 27.5 <= freq <= 4186 then FreqToPitchClass(freq) else -1
           - Accumulate chromagram: loop reading FFT4096 frames (Bass.ChannelGetData with DataFlags.FFT4096), sum fftBuffer[bin] into chroma[pitchClass] for valid bins
           - Track progress: compute bytes read vs total, map to 50-100% range, call onProgress every ~2% (not every frame)
           - Check ct.IsCancellationRequested periodically (every ~100 frames)
           - Limit to maxSeconds worth of audio (check via ChannelBytes2Seconds of current position)
           - Call `KeyDetector.DetectKeyFromChromagram(chroma)` to get (key, confidence)
           - If key is null or em dash: mark KeyFailed = true
         - Free key stream BEFORE freeing GCHandle (critical: same pattern as WaveformGenerator)
         - Build and return AnalysisResult with all fields populated
         - In finally block: ensure stream freed before handle freed, defensive cleanup
       - IMPORTANT anti-patterns to avoid:
         - Do NOT use BassFlags.FX_BPM_BKGRND (breaks CancellationToken integration)
         - Do NOT share decode stream between BPM and key phases (create fresh stream for key)
         - Always free stream BEFORE handle.Free()
         - Pin GCHandle with GCHandleType.Pinned

    3. Create `src/Audex/Audio/AnalysisCache.cs` — binary disk cache:
       - Static class `AnalysisCache` in namespace `Audex.Audio`
       - Using System.IO, System.Linq, Audex.Utils, Audex.UI (for WaveformCache.ComputeCacheKey)
       - Private const string CacheSubfolder = "Audex"; private const string AnalysisSubfolder = "analysis"
       - Private const string CacheExtension = ".bka"
       - Private const byte CacheVersion = 1
       - Private const int MaxEntries = 2000
       - Private static method `string GetCachePath(string key)`: returns Path.Combine(Path.GetTempPath(), CacheSubfolder, AnalysisSubfolder, key + CacheExtension). Create directory if not exists.
       - Public static `AnalysisResult? Read(string cacheKey)`:
         - Get cache path; if file does not exist return null
         - Read binary: version byte (reject if != CacheVersion), then: float bpm, byte keyLen, byte[] keyUtf8, float bpmConf, float keyConf, long ticks, byte failFlags
         - Touch LastWriteTimeUtc for LRU ordering
         - Construct and return AnalysisResult:
           - DetectedBpm = bpm > 0 ? (int)Math.Round(bpm) : null (if failFlags bit 0 set, BpmFailed = true)
           - DetectedKey = keyLen > 0 ? Encoding.UTF8.GetString(keyUtf8) : null (if failFlags bit 1 set, KeyFailed = true)
           - BpmConfidence = bpmConf, KeyConfidence = keyConf
           - FailureReason = both failed ? "unable to detect" : null
         - Wrap in try/catch; return null on any error
       - Public static `void Write(string cacheKey, AnalysisResult result)`:
         - Get cache path
         - Write binary: version (1), float bpm (result.DetectedBpm ?? 0f), byte keyLen, byte[] keyUtf8, float bpmConf, float keyConf, long DateTime.UtcNow.Ticks, byte failFlags (bit 0 = BpmFailed, bit 1 = KeyFailed)
         - Call EvictIfNeeded() after write
         - Wrap in try/catch; log errors via Logger
       - Public static `void Delete(string cacheKey)`: delete file if exists. For re-analyze flow.
       - Private static `void EvictIfNeeded()`:
         - Get analysis subdirectory
         - Count .bka files; if count <= MaxEntries return
         - Sort by LastWriteTimeUtc ascending, delete oldest until count <= MaxEntries
         - Swallow individual delete failures

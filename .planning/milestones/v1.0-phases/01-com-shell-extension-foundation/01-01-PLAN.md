    Create a .NET Framework 4.8 class library project (NOT .NET Core/.NET 5+ — COM shell extensions require .NET Framework for in-process COM activation in prevhost.exe).

    **Solution and project:**
    - Create `Audex.sln` at repo root
    - Create `src/Audex/Audex.csproj` as a Class Library targeting .NET Framework 4.8, x64 platform, with `<RegisterForComInterop>true</RegisterForComInterop>` and `<ComVisible>true</ComVisible>` in AssemblyInfo
    - Output type: Library (DLL)
    - Add NuGet package references: `Serilog` (2.x), `Serilog.Sinks.File` (5.x), `ini-parser-netstandard` (2.x) for INI parsing

    **AssemblyInfo.cs:**
    - `[assembly: ComVisible(true)]`
    - `[assembly: Guid("GENERATE-NEW-GUID")]` — generate a unique assembly GUID
    - Assembly version 1.0.0.0

    **app.manifest:**
    - DPI awareness: `<dpiAware>true/PM</dpiAware>` and `<dpiAwareness>PerMonitorV2</dpiAwareness>` for high-DPI support
    - Requested execution level: `asInvoker` (preview handlers run in prevhost.exe, no elevation needed)

    **COM Interface definitions (in Interop/ folder):**
    Each interface must use `[ComImport]`, `[InterfaceType(ComInterfaceType.InterfaceIsIUnknown)]`, and the correct IID GUID.

    `IPreviewHandler.cs`:
    ```csharp
    [ComImport, InterfaceType(ComInterfaceType.InterfaceIsIUnknown)]
    [Guid("8895b1c6-b41f-4c1c-a562-0d564250836f")]
    public interface IPreviewHandler
    {
        void SetWindow(IntPtr hwnd, ref RECT rect);
        void SetRect(ref RECT rect);
        void DoPreview();
        void Unload();
        void SetFocus();
        void QueryFocus(out IntPtr phwnd);
        [PreserveSig] uint TranslateAccelerator(ref MSG pmsg);
    }
    ```

    `IInitializeWithStream.cs` (IID: b824b49d-22ac-4161-ac8a-9916e8fa3f7f):
    - `Initialize(IStream pstream, uint grfMode)`

    `IObjectWithSite.cs` (IID: fc4801a3-2ba9-11cf-a229-00aa003d7352):
    - `SetSite([MarshalAs(UnmanagedType.IUnknown)] object pUnkSite)`
    - `GetSite(ref Guid riid, [MarshalAs(UnmanagedType.IUnknown)] out object ppvSite)`

    `IOleWindow.cs` (IID: 00000114-0000-0000-C000-000000000046):
    - `GetWindow(out IntPtr phwnd)`
    - `ContextSensitiveHelp(bool fEnterMode)`

    `IPreviewHandlerFrame.cs` (IID: fec87aaf-35f9-447a-adb7-20234fb69178):
    - `GetWindowContext(out IntPtr pinfo)`
    - `TranslateAccelerator(ref MSG pmsg)`

    Also define `RECT` and `MSG` structs via `[StructLayout(LayoutKind.Sequential)]` in a `NativeStructs.cs` file in the Interop folder.

    **Important:** Use `System.Runtime.InteropServices.ComTypes.IStream` for the IStream parameter (do NOT define a custom IStream — .NET provides one).

  <name>Task 2: Implement config, logging, and path utilities</name>
  <files>

  <action>
    **PathHelper.cs** — Static utility class for AppData path resolution:
    - `GetAppDataRoot()` → returns `%LOCALAPPDATA%\Audex\` (use `Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData)`)
    - `GetConfigPath()` → returns `%LOCALAPPDATA%\Audex\config.ini`
    - `GetLogDirectory()` → returns `%LOCALAPPDATA%\Audex\logs\`
    - `GetLogFilePath()` → returns `%LOCALAPPDATA%\Audex\logs\Audex.log`
    - `EnsureDirectories()` → creates AppData root and logs subdirectory if they don't exist
    - All paths use LOCALAPPDATA (not APPDATA roaming) for low-integrity process compatibility (PREV-05)

    **Logger.cs** — Singleton wrapper around Serilog:
    - `Initialize()` — call `PathHelper.EnsureDirectories()`, then configure Serilog with:
      - Rolling file sink writing to `PathHelper.GetLogFilePath()`
      - Rolling interval: daily
      - File size limit: 10MB
      - Retained file count: 3
      - Output template: `[{Timestamp:yyyy-MM-dd HH:mm:ss.fff}] [{Level:u3}] {Message:lj}{NewLine}{Exception}`
    - `SetLevel(string level)` — accepts "debug", "info", "warning", "error"; maps to Serilog `LogEventLevel`
    - Static methods: `Debug(string msg)`, `Info(string msg)`, `Warn(string msg)`, `Error(string msg, Exception ex = null)`
    - Thread-safe (Serilog handles this internally)
    - If Serilog initialization fails (e.g., disk full), swallow the exception — preview handler should still function without logging

    **AppConfig.cs** — POCO class holding configuration values:
    ```csharp
    public class AppConfig
    {
        public List<string> SupportedExtensions { get; set; }
        public string LogLevel { get; set; }
        public int DebounceMs { get; set; }
    }
    ```
    - Default values: Extensions = `.wav,.mp3,.flac,.aiff,.ogg,.aac,.wma,.opus,.m4a`; LogLevel = `info`; DebounceMs = `150`

    **ConfigManager.cs** — Reads INI config file:
    - `Load()` → reads `PathHelper.GetConfigPath()` using ini-parser library
    - If config file doesn't exist, return `AppConfig` with defaults (DO NOT create the file — first-run experience should work without config file)
    - If config file exists but has missing keys, fill in defaults for missing keys
    - INI structure:
      ```ini
      [FileTypes]
      Extensions=.wav,.mp3,.flac,.aiff,.ogg,.aac,.wma,.opus,.m4a

      [Logging]
      Level=info

      [Performance]
      DebounceMs=150
      ```
    - `GetExtensions()` → returns `List<string>` of supported extensions (parsed from comma-separated config value)
    - Extensions are lowercased and trimmed (normalize user input)
    - Log any config parsing errors via Logger (if Logger is initialized) or silently fall back to defaults
  </action>

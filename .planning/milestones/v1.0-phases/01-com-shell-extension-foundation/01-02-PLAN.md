    **AudioPreviewHandler.cs** — The main COM-visible class implementing all required interfaces:

    ```csharp
    [ComVisible(true)]
    [ClassInterface(ClassInterfaceType.None)]
    [Guid("SAME-GUID-AS-ComGuids.CLSID")]
    [ProgId("Audex.AudioPreviewHandler")]
    public class AudioPreviewHandler : IPreviewHandler, IInitializeWithStream, IObjectWithSite, IOleWindow
    ```

    **IInitializeWithStream implementation:**
    - `Initialize(IStream pstream, uint grfMode)`:
      - Store the IStream reference in a member field (`_stream`)
      - Do NOT read any data — lazy loading per Microsoft guidance
      - Log: `Logger.Debug("Initialize called")`
      - Return S_OK (0)

    **IPreviewHandler implementation:**
    - `SetWindow(IntPtr hwnd, ref RECT rect)`:
      - Store parent HWND (`_hwndParent`) and rect (`_rcParent`)
      - If preview window already exists, reparent and resize it using Win32 `SetParent` and `SetWindowPos` via P/Invoke
      - Log parent HWND value at debug level

    - `SetRect(ref RECT rect)`:
      - Update stored rect
      - If preview window exists, resize it to new rect via `SetWindowPos`

    - `DoPreview()`:
      - THIS is where all file reading and UI creation happens
      - **Debounce logic:**
        - Track `_isFirstLoad` boolean (starts true)
        - If `_isFirstLoad`, set to false and proceed immediately
        - If NOT first load, use `System.Threading.Timer` or `System.Windows.Forms.Timer` with configurable delay from `ConfigManager.Load().DebounceMs` (default 150ms)
        - On timer tick: cancel timer, proceed with actual preview
        - If DoPreview is called again before timer fires: cancel old timer, restart (this is the debounce — only the last call wins)
      - **Actual preview work (after debounce):**
        1. Read file info from `_stream` using `AudioHeaderParserFactory.Parse()`
        2. If parsing fails, log error and set error state (UI will show error banner — implemented in Plan 03)
        3. Store parsed `AudioFileInfo` in member field
        4. Signal the preview window to render (preview window created/managed by Plan 03 — for now, just store the data and call a virtual/abstract method or raise an event that Plan 03 will wire up)
      - Wrap entire method in try/catch — log exceptions, never let them propagate to COM caller (would crash prevhost.exe)

    - `Unload()`:
      - Release IStream: set `_stream = null` (COM reference will be released by GC, but explicitly null to indicate we're done)
      - If using `Marshal.ReleaseComObject` on the IStream, do so carefully (only if we own the reference)
      - Destroy preview window if it exists (call cleanup method — Plan 03 will implement the window, this plan just nulls the reference)
      - Kill any pending debounce timer
      - Reset `_isFirstLoad` to true (next Initialize + DoPreview pair starts fresh)
      - Log: `Logger.Debug("Unload called — resources released")`

    - `SetFocus()`: Set focus to preview window HWND via Win32 `SetFocus` P/Invoke
    - `QueryFocus(out IntPtr phwnd)`: Return `GetFocus()` via P/Invoke
    - `TranslateAccelerator(ref MSG pmsg)`: Forward to IPreviewHandlerFrame if site provides one, else return S_FALSE (1)

    **IObjectWithSite implementation:**
    - `SetSite(object pUnkSite)`: Store site reference. Try to `QueryInterface` for `IPreviewHandlerFrame` and cache it.
    - `GetSite(ref Guid riid, out object ppvSite)`: Return stored site or `E_NOINTERFACE`

    **IOleWindow implementation:**
    - `GetWindow(out IntPtr phwnd)`: Return preview window HWND (or IntPtr.Zero if no window)
    - `ContextSensitiveHelp(bool fEnterMode)`: Return `E_NOTIMPL`

    **P/Invoke declarations** (can be in a nested NativeMethods class or separate file):
    - `SetParent(IntPtr hWndChild, IntPtr hWndNewParent)`
    - `SetWindowPos(IntPtr hWnd, IntPtr hWndInsertAfter, int X, int Y, int cx, int cy, uint uFlags)`
    - `SetFocus(IntPtr hWnd)`
    - `GetFocus() -> IntPtr`

    **AudioFileInfo.cs** — Data class for parsed metadata:
    ```csharp
    public class AudioFileInfo
    {
        public string FileName { get; set; }
        public long FileSize { get; set; }         // bytes
        public string Format { get; set; }          // "WAV", "MP3", "FLAC", etc.
        public int SampleRate { get; set; }         // e.g., 44100
        public int BitDepth { get; set; }           // e.g., 16, 24 (0 if not applicable, e.g., MP3)
        public int Channels { get; set; }           // 1 = mono, 2 = stereo
        public double Duration { get; set; }        // seconds
        public int BitRate { get; set; }            // kbps (for compressed formats)
        public bool ParseSucceeded { get; set; }
        public string ParseError { get; set; }      // null if succeeded
    }
    ```

    **WavHeaderParser.cs** — Parse WAV RIFF header from IStream:
    - Read first 44 bytes (minimum WAV header) from IStream using `IStream.Read()`
    - Validate RIFF magic bytes ("RIFF") and WAVE format ("WAVE")
    - Handle non-standard WAV files: scan for "fmt " chunk rather than assuming fixed 44-byte layout (some WAVs have extra chunks before fmt)
    - Parse fmt chunk: audio format (1=PCM), channels, sample rate, byte rate, block align, bits per sample
    - Scan for "data" chunk to get data size
    - Calculate duration: `dataSize / byteRate` (for PCM)
    - For non-PCM WAV (compressed), set duration to 0 and note "compressed WAV" in format
    - Return populated AudioFileInfo with Format="WAV"
    - Handle truncated files gracefully: if stream ends before expected, return partial info with ParseError

    **Mp3HeaderParser.cs** — Parse MP3 frame header:
    - Skip ID3v2 tag if present: check first 3 bytes for "ID3", read tag size from bytes 6-9 (syncsafe integer), seek past it
    - Find first valid MPEG frame sync: scan for 0xFF 0xFB/0xFA/0xF3/0xF2 (11 set bits frame sync)
    - Parse frame header (4 bytes): MPEG version (1/2/2.5), layer (I/II/III), bitrate index, sample rate index, channel mode
    - Look up bitrate from standard MPEG bitrate tables (Layer III, MPEG1: 32/40/48/56/64/80/96/112/128/160/192/224/256/320 kbps)
    - Look up sample rate from table (MPEG1: 44100/48000/32000)
    - Estimate duration: get stream size via `IStream.Stat()`, then `duration = (streamSize - id3Size) * 8 / (bitrate * 1000)`
    - This is a rough estimate (CBR assumption); accuracy is acceptable for Phase 1 placeholder display
    - Set BitDepth to 0 (not applicable for MP3)
    - Return populated AudioFileInfo with Format="MP3"
    - Limit frame sync scanning to first 64KB — if no valid frame found, return ParseError

    **FlacHeaderParser.cs** — Parse FLAC STREAMINFO metadata block:
    - Validate first 4 bytes are "fLaC" (FLAC stream marker)
    - Read METADATA_BLOCK_HEADER (4 bytes): is-last flag, block type (0=STREAMINFO), block length
    - Read STREAMINFO block (34 bytes): min/max block size, min/max frame size, sample rate (20 bits), channels (3 bits, value is channels-1), bit depth (5 bits, value is bps-1), total samples (36 bits)
    - Calculate duration: `totalSamples / sampleRate`
    - FLAC STREAMINFO bit layout is packed (not byte-aligned) — use careful bit shifting:
      - Sample rate: bytes 10-12, upper 20 bits of the 3 bytes starting at offset 10
      - Channels: next 3 bits after sample rate
      - Bit depth: next 5 bits
      - Total samples: next 36 bits (spans bytes 13-17)
    - Return populated AudioFileInfo with Format="FLAC"

    **AudioHeaderParserFactory.cs** — Factory that selects parser by extension:
    ```csharp
    public static class AudioHeaderParserFactory
    {
        public static AudioFileInfo Parse(IStream stream, string fileName, long fileSize)
        {
            string ext = Path.GetExtension(fileName)?.ToLowerInvariant();
            try
            {
                return ext switch
                {
                    ".wav" => WavHeaderParser.Parse(stream),
                    ".mp3" => Mp3HeaderParser.Parse(stream),
                    ".flac" => FlacHeaderParser.Parse(stream),
                    _ => new AudioFileInfo
                    {
                        Format = ext?.TrimStart('.').ToUpperInvariant() ?? "Unknown",
                        ParseSucceeded = true,
                        ParseError = null
                        // Other fields remain default (0) — info not available without BASS
                    }
                };
            }
            catch (Exception ex)
            {
                Logger.Error($"Header parsing failed for {fileName}: {ex.Message}", ex);
                return new AudioFileInfo
                {
                    FileName = fileName,
                    FileSize = fileSize,
                    Format = ext?.TrimStart('.').ToUpperInvariant() ?? "Unknown",
                    ParseSucceeded = false,
                    ParseError = ex.Message
                };
            }
        }
    }
    ```
    - For extensions without a dedicated parser (AIFF, OGG, AAC, WMA, OPUS, M4A), return AudioFileInfo with filename, filesize, and format name but zero for sample rate/duration/etc. The UI will show "Playback coming soon" for these.
    - Always set FileName and FileSize regardless of parse success

    **IStream reading helper:** Create a small utility method to read N bytes from an IStream into a byte array, handling the COM marshaling. Reading from `System.Runtime.InteropServices.ComTypes.IStream`:
    ```csharp
    static byte[] ReadBytes(IStream stream, int count)
    {
        byte[] buffer = new byte[count];
        IntPtr bytesReadPtr = Marshal.AllocCoTaskMem(sizeof(int));
        try
        {
            stream.Read(buffer, count, bytesReadPtr);
            int bytesRead = Marshal.ReadInt32(bytesReadPtr);
            if (bytesRead < count)
                Array.Resize(ref buffer, bytesRead);
            return buffer;
        }
        finally
        {
            Marshal.FreeCoTaskMem(bytesReadPtr);
        }
    }
    ```

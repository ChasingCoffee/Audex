    **ThemeHelper.cs** — Static helper for dark/light mode detection:
    - `IsSystemInDarkMode()` → Query `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme` via `Microsoft.Win32.Registry`. Returns true if value is 0 (dark mode).
    - `GetBackgroundColor()` → Dark: `Color.FromArgb(32, 32, 32)`, Light: `Color.FromArgb(255, 255, 255)`
    - `GetTextColor()` → Dark: `Color.FromArgb(255, 255, 255)`, Light: `Color.FromArgb(0, 0, 0)`
    - `GetSecondaryTextColor()` → Dark: `Color.FromArgb(170, 170, 170)`, Light: `Color.FromArgb(100, 100, 100)` (for labels, secondary info)
    - `GetPlaceholderColor()` → Dark: `Color.FromArgb(50, 50, 50)`, Light: `Color.FromArgb(230, 230, 230)` (for grayed-out skeleton areas)
    - `GetErrorBannerBackgroundColor()` → Dark: `Color.FromArgb(60, 30, 30)`, Light: `Color.FromArgb(255, 240, 240)` (subtle red tint)
    - `GetErrorBannerTextColor()` → Dark: `Color.FromArgb(255, 180, 180)`, Light: `Color.FromArgb(180, 0, 0)`
    - `GetBorderColor()` → Dark: `Color.FromArgb(60, 60, 60)`, Light: `Color.FromArgb(210, 210, 210)` (for separator lines)
    - All color methods are computed from `IsSystemInDarkMode()` — no caching (theme can change between calls)

    **ErrorBanner.cs** — Error overlay rendering:
    - `Draw(Graphics g, Rectangle bounds, string errorMessage, string logFilePath)`:
      - Draw semi-transparent background rectangle at top of preview area (height ~50px)
      - Render error text: "This file can't be previewed. See log for details: {logFilePath}" (per user decision: user-friendly language, no icons, no retry link)
      - Text color from ThemeHelper.GetErrorBannerTextColor()
      - Background from ThemeHelper.GetErrorBannerBackgroundColor()
    - `GetBannerHeight()` → returns height in pixels (scaled by DPI)

    **LayoutRenderer.cs** — Renders the placeholder preview layout:
    - `Render(Graphics g, Rectangle bounds, AudioFileInfo info, bool showError, string errorMessage)`:
      - Get all colors from ThemeHelper
      - **Layout structure (top to bottom):**
        1. **Error banner** (if showError): Render via ErrorBanner.Draw() at top, previous content stays dimmed underneath (draw semi-transparent overlay on content below)
        2. **File info panel** (top ~30% of remaining space):
           - Filename (bold, primary text color)
           - File size (formatted: KB/MB)
           - Format: e.g., "WAV - PCM" or "MP3" or "FLAC"
           - If parsed successfully: sample rate (e.g., "44,100 Hz"), bit depth (e.g., "24-bit", skip if 0), channels ("Stereo" / "Mono" / "N channels"), duration (formatted as mm:ss or hh:mm:ss)
           - If format has no parser (AIFF, OGG, etc.): Show filename/size/format, then italic note: "Playback coming soon" (per user decision)
        3. **Waveform placeholder** (middle ~45% of space):
           - Grayed-out rectangle with ThemeHelper.GetPlaceholderColor() fill
           - Thin border with ThemeHelper.GetBorderColor()
           - Centered text in secondary color: "Waveform" (hint at future feature)
        4. **Controls placeholder** (bottom ~25% of space):
           - Grayed-out rectangle, same styling as waveform placeholder
           - Centered text in secondary color: "Controls"
      - **DPI scaling:** All sizes (font size, padding, margins, placeholder heights) must be scaled by DPI. Use `g.DpiX / 96.0f` as scale factor. Base font size: 9pt for body text, 11pt for filename.
      - Use `StringFormat` with `Trimming = EllipsisCharacter` for long filenames
      - Layout proportions are flexible — adapt to available space, maintain minimum padding of 8px (scaled)

    - `FormatFileSize(long bytes)` → "1.23 MB", "456 KB", etc.
    - `FormatDuration(double seconds)` → "3:45" or "1:02:30"

    **PreviewWindow.cs** — Win32 window management:
    - Manages a child HWND parented to Explorer's preview pane
    - **Window creation:**
      - Register window class (`RegisterClassEx`) with custom WndProc
      - Create child window (`CreateWindowEx`) with `WS_CHILD | WS_VISIBLE`
      - Enable double-buffering to prevent flicker during paint
    - **WndProc message handling:**
      - `WM_PAINT`: Create `Graphics` from `BeginPaint`, call `LayoutRenderer.Render()`, `EndPaint`. Use double-buffered approach: paint to offscreen bitmap, then blit to screen.
      - `WM_SIZE`: Recalculate layout, `InvalidateRect` to trigger repaint (responsive resize per user decision)
      - `WM_SETTINGCHANGE`: If `lParam == "ImmersiveColorSet"`, repaint with new theme colors (per research Pattern 4)
      - `WM_TIMER` (debounce timer): If timer ID matches debounce timer, kill timer and execute the pending DoPreview work
      - `WM_ERASEBKGND`: Return 1 (handled) to prevent flicker — we paint the entire background in WM_PAINT
    - **Loading spinner:**
      - Track loading start time
      - If loading takes > 200ms (per user decision), show a simple text-based spinner ("Loading..." or a rotating dots animation) centered in the preview area
      - Spinner is rendered in WM_PAINT when in loading state
      - Use a ~100ms timer to advance spinner animation frames
      - Cancel spinner when loading completes or Unload() is called
    - **Public methods:**
      - `Create(IntPtr parentHwnd, RECT rect)` — create the window
      - `UpdateContent(AudioFileInfo info)` — store new file info, invalidate to repaint
      - `ShowError(string message)` — set error state, invalidate to repaint (error banner + dimmed content per user decision)
      - `ClearError()` — clear error state
      - `Resize(RECT rect)` — reposition/resize
      - `Destroy()` — destroy window, release GDI objects

    **AudioPreviewHandler.cs** — Wire PreviewWindow into lifecycle (update existing file from Plan 02):
    - In `DoPreview()` (after debounce resolves):
      1. Create `PreviewWindow` if not exists
      2. Start loading timer (for >200ms spinner)
      3. Parse file via `AudioHeaderParserFactory.Parse()`
      4. Cancel loading timer
      5. If parse succeeded: `_previewWindow.UpdateContent(fileInfo)`
      6. If parse failed: `_previewWindow.ShowError(fileInfo.ParseError)`, log full error
    - In `Unload()`: Call `_previewWindow.Destroy()`, set to null
    - In `SetWindow()`: If preview window exists, call `_previewWindow.Resize(rect)` and reparent
    - In `SetRect()`: If preview window exists, call `_previewWindow.Resize(rect)`

    **Error flow (per user decisions):**
    - Parse error → ErrorBanner at top with "This file can't be previewed. See log for details: {PathHelper.GetLogFilePath()}"
    - Previous content stays dimmed underneath (semi-transparent overlay)
    - During rapid browsing, suppress errors for debounced/skipped files — only show error if the final "winning" file fails (debounce handles this naturally since only the last file is loaded)

    **scripts/register.ps1** — PowerShell script for dev registration:
    ```powershell
    # Register Audex preview handler
    # Run as Administrator
    #Requires -RunAsAdministrator

    $dllPath = Join-Path $PSScriptRoot "..\src\Audex\bin\x64\Release\Audex.dll"
    if (-not (Test-Path $dllPath)) {
        $dllPath = Join-Path $PSScriptRoot "..\src\Audex\bin\x64\Debug\Audex.dll"
    }

    if (-not (Test-Path $dllPath)) {
        Write-Error "DLL not found. Build the project first."
        exit 1
    }

    # Stop any running prevhost.exe to release loaded DLLs
    Get-Process prevhost -ErrorAction SilentlyContinue | Stop-Process -Force

    # Register with regasm
    $regasm = Join-Path $env:WINDIR "Microsoft.NET\Framework64\v4.0.30319\RegAsm.exe"
    & $regasm $dllPath /codebase /tlb
    if ($LASTEXITCODE -ne 0) {
        Write-Error "Registration failed"
        exit 1
    }

    # Restart Explorer to pick up new handler
    Write-Host "Registration complete. Restart Explorer or log out/in to activate."
    Write-Host "To restart Explorer now, run: Stop-Process -Name explorer -Force"
    ```

    **scripts/unregister.ps1** — PowerShell script for dev unregistration:
    ```powershell
    # Unregister Audex preview handler
    # Run as Administrator
    #Requires -RunAsAdministrator

    $dllPath = Join-Path $PSScriptRoot "..\src\Audex\bin\x64\Release\Audex.dll"

    $regasm = Join-Path $env:WINDIR "Microsoft.NET\Framework64\v4.0.30319\RegAsm.exe"
    & $regasm $dllPath /unregister

    ```

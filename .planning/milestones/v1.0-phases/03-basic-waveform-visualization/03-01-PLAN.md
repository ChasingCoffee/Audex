**WaveformGenerator.cs** (src/Audex/Audio/WaveformGenerator.cs):

Create a static class `WaveformGenerator` with a single public method:

```csharp
public static float[]? Generate(byte[] audioData, CancellationToken ct, Action<int, float>? onBarReady = null)
```

Implementation:
1. Pin `audioData` via `GCHandle.Alloc(audioData, GCHandleType.Pinned)`.
2. Create a BASS decode stream: `Bass.CreateStream(ptr, 0, audioData.Length, BassFlags.Decode | BassFlags.Float)`. This is a PURE decode stream -- do NOT add it to BassMix or the mixer. If stream creation fails, free handle and return null.
3. Get total byte length via `Bass.ChannelGetLength(waveStream)` and channel count via `Bass.ChannelGetInfo`.
4. Target a canonical peak count of 2000 bars (independent of display width -- renderer downsamples at paint time).
5. Compute `samplesPerBar = totalSampleFrames / 2000` (where totalSampleFrames = totalBytes / sizeof(float) / channelCount). Clamp `samplesPerBar` to minimum 1. Cap target bars to actual sample frame count for very short files.
6. Decode loop: Read 4096-float chunks via `Bass.ChannelGetData(waveStream, buffer, buffer.Length * sizeof(float))`. For each float, take `Math.Abs(value)` and track max across ALL channels in each sample frame (divide sample index by channelCount to get frame number). When `samplesInBar >= samplesPerBar`, emit `Math.Min(1f, barPeak)` to the peaks list, reset, and invoke `onBarReady(barIndex, peakValue)` if provided.
7. Check `ct.IsCancellationRequested` on each chunk read -- if cancelled, call `Bass.StreamFree` then `handle.Free()` and return null.
8. After loop, flush any remaining partial bar as a final peak.
9. CRITICAL ordering: call `Bass.StreamFree(waveStream)` BEFORE `handle.Free()`. This prevents BASS from accessing freed memory.
10. Return the float[] array.

Use `try/finally` to guarantee cleanup (StreamFree + handle.Free) even on exceptions.

**WaveformCache.cs** (src/Audex/UI/WaveformCache.cs):

Create a static class `WaveformCache` with these methods:

```csharp
public static string ComputeCacheKey(byte[] audioData)
```
- Use `SHA256.Create()` to hash `audioData`, convert to lowercase hex string.

```csharp
public static string GetCachePath(string key)
```
- Returns `Path.Combine(Path.GetTempPath(), "Audex", key + ".wf")`.
- Creates the directory if it doesn't exist.

```csharp
public static float[]? ReadCache(string key)
```
- Get path from `GetCachePath(key)`. If file doesn't exist, return null.
- Read binary: first 4 bytes = int32 bar count, then N x float32 values.
- Wrap in try/catch -- return null on any read error (corrupt cache file).
- Touch file's LastWriteTime to current time on successful read (for LRU eviction).

```csharp
public static void WriteCache(string key, float[] peaks)
```
- Write binary: int32 count + float32[] values.
- After writing, call `EvictIfNeeded()`.

```csharp
public static void EvictIfNeeded(long maxBytes = 50L * 1024 * 1024)
```
- Get all `.wf` files in cache directory, sort by LastWriteTime ascending.
- Sum total size. While total > maxBytes, delete oldest file (swallow exceptions on individual deletes).

Use `BinaryWriter`/`BinaryReader` for I/O. All methods should be defensive (catch and log exceptions, never crash the caller).

**WaveformRenderer.cs** (src/Audex/UI/WaveformRenderer.cs):

Create a static class following the ControlBarRenderer pattern. It receives all state, does not own it. Layout rectangles cached in static fields for HitTest.

**Public API:**

```csharp
public static void Draw(Graphics g, Rectangle bounds, float[]? peaks, int barsReady,
    double currentPosition, double totalDuration, float dpiScale,
    bool isHovering, Point hoverPoint, bool isDragging, double dragPosition,
    bool waveformUnavailable)
```

```csharp
public static bool HitTest(Point point, Rectangle bounds)
// Returns true if point is within waveform bounds (used by PreviewWindow for cursor and click handling)
```

**Draw implementation details:**

1. **Background**: Fill `bounds` with `ThemeHelper.GetWaveformBackgroundColor()`. Add 1px top border using `ThemeHelper.GetBorderColor()`.

2. **"Waveform unavailable" state**: If `waveformUnavailable` is true and `peaks` is null, draw centered text "Waveform unavailable" in secondary text color. Return.

3. **Layout constants** (DPI-scaled):
   - `int padding = (int)(8 * dpiScale)` on left/right
   - `int timeLabelHeight = (int)(14 * dpiScale)` at bottom of waveform area for start/end time labels
   - Waveform bar area = bounds minus left/right padding and bottom timeLabelHeight
   - `int barGap = Math.Max(1, (int)(1.5f * dpiScale))` per user decision (1-2px gap)
   - Compute `barCount = (waveformWidth + barGap) / (barWidth + barGap)` where `barWidth = Math.Max(1, (int)(2.5f * dpiScale))` as starting point. Adjust so bars fill the available width evenly.

4. **Peak downsampling**: If `peaks` has 2000 entries but `barCount` is (e.g.) 100, downsample by averaging groups: for bar `i`, average peaks from `i * peaksPerBar` to `(i+1) * peaksPerBar - 1`. If `barsReady < peaks.Length`, only draw bars up to the proportional index in the downsampled array (progressive reveal).

5. **Bar rendering** (per user decisions):
   - Bars are mirrored from centerY of the waveform area (extend up and down symmetrically)
   - `int halfHeight = Math.Max(1, (int)(barAmplitude * maxHalfHeight))` -- minimum 1-2px per user decision (track shape always visible)
   - Color: `ThemeHelper.GetWaveformBarColor(barAmplitude)` for bars ahead of playhead, `ThemeHelper.GetWaveformPlayedBarColor(barAmplitude)` for bars behind playhead
   - Dimming transition: compare bar X position to playhead X position. Bars entirely to the left of playhead get played color. Sharp edge at playhead position.
   - Rounded tops: Use `GraphicsPath` with `AddArc` for the top of each bar (mirrored, so also rounded at bottom). Small radius `Math.Min(barWidth / 2, (int)(1.5f * dpiScale))`. For bars shorter than 2*radius, fall back to plain FillRectangle.
   - Enable `SmoothingMode.AntiAlias` before drawing bars.

6. **Center line**: Draw thin 1px horizontal line at centerY using `ThemeHelper.GetWaveformCenterLineColor()`.

7. **Playhead** (per user decisions):
   - Only draw if `totalDuration > 0`.
   - Compute playhead X: if `isDragging`, use `dragPosition / totalDuration`, else use `currentPosition / totalDuration`, mapped to pixel X within waveform area.
   - Draw vertical line (1.5px pen, white) from waveform area top to bottom.
   - Draw small downward-pointing filled triangle at top of waveform: `PointF[] { (x-5, top), (x+5, top), (x, top+10) }` (DPI-scaled). Color: same white.

8. **Hover guide line** (per user decisions):
   - Only draw if `isHovering` and `!isDragging` and mouse is within waveform bounds.
   - Draw thin vertical line at `hoverPoint.X` using `ThemeHelper.GetWaveformGuideLineColor()`.

9. **Hover time tooltip** (per user decisions):
   - When `isHovering`, compute time from hoverPoint.X position ratio * totalDuration.
   - Draw tooltip: small rounded rectangle with time text (formatted via `LayoutRenderer.FormatDuration`) near cursor. Position above the cursor by ~20px (DPI-scaled). Clamp X so tooltip doesn't exceed waveform bounds left/right.
   - Tooltip background: semi-transparent dark (dark theme) or semi-transparent light (light theme). Text color: white (dark) or black (light).

10. **Time labels** (per user decisions):
    - Draw "0:00" at left-bottom of waveform area, and `LayoutRenderer.FormatDuration(totalDuration)` at right-bottom.
    - Font: Segoe UI 7.5pt. Color: `ThemeHelper.GetWaveformTimeLabelColor()`.

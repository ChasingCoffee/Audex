int controlBarHeight = ControlBarRenderer.GetControlBarHeight(dpiScale);

**4. Mouse event updates:**

In `OnMouseMove`:
- Before checking control bar hit test, check if point is in waveform area via `WaveformRenderer.HitTest(e.Location, _waveformBounds)`.
- If hovering waveform: set `_isHoveringWaveform = true`, `_waveformHoverPoint = e.Location`, `Cursor = Cursors.Cross` (crosshair per user decision).
- If dragging waveform (`_isWaveformDragging` is true and mouse button is down): compute `_waveformDragPosition = (ratio * duration)` from X position. Invalidate waveform bounds only. Do NOT seek audio during drag (visual only per user decision).
- If NOT hovering waveform: set `_isHoveringWaveform = false`, check control bar zones as before.
- Invalidate `_waveformBounds` on hover changes (for guide line + tooltip).

In `OnMouseDown`:
- If click is in waveform area:
  - Per user decision: Click = instant seek (jump on click, not on release).
  - Compute time from X ratio: `double seekTime = ratio * duration`.
  - Call `_player.Seek(seekTime)`.
  - If `_player.State == AudioPlayerState.Stopped` or `_player.State == AudioPlayerState.Idle`: also call `_player.Play()` (per user decision: clicking while stopped starts playback).
  - Set `_isWaveformDragging = true`, `_waveformDragPosition = seekTime`.
  - Invalidate waveform + control bar.
  - Return (do not fall through to control bar hit test).

In `OnMouseUp`:
- If `_isWaveformDragging`:
  - Per user decision: audio seeks to drag position on release.
  - Call `_player.Seek(_waveformDragPosition)`.
  - Set `_isWaveformDragging = false`.
  - Per user decision: control bar time display updates on release.
  - Invalidate waveform + control bar.
  - Return.

In `OnMouseLeave`:
- Set `_isHoveringWaveform = false`.
- Set `_isWaveformDragging = false`.
- Invalidate `_waveformBounds`.
- Continue with existing control bar leave logic.

**5. New public methods for waveform lifecycle:**

```csharp
public void StartWaveformGeneration(byte[] audioData, double totalDuration)
```
- Cancel any in-progress generation: `_waveCts?.Cancel(); _waveCts?.Dispose();`
- Create new CTS: `_waveCts = new CancellationTokenSource()`
- Reset waveform state: `_waveformPeaks = null; _waveformBarsReady = 0; _waveformUnavailable = false;`
- Increment `_currentGenerationId` via `Interlocked.Increment`.
- Check cache first: `string key = WaveformCache.ComputeCacheKey(audioData);`
  - If `WaveformCache.ReadCache(key)` returns non-null: set `_waveformPeaks = cached`, `_waveformBarsReady = cached.Length`, `Invalidate(_waveformBounds)`, return (no background thread needed).
- Start background thread (IsBackground=true):
  - Capture `generationId` and `key` and `ct`.
  - Pre-allocate `_waveformPeaks = new float[2000]` (or whatever the target count is).
  - Call `WaveformGenerator.Generate(audioData, ct, onBarReady)` where `onBarReady` is:
    ```csharp
    (barIndex, peak) => {
        if (ct.IsCancellationRequested) return;
        if (!IsHandleCreated || IsDisposed) return;
        try {
            Invoke(new Action(() => {
                if (_currentGenerationId != generationId) return; // stale
                if (_waveformPeaks != null && barIndex < _waveformPeaks.Length)
                    _waveformPeaks[barIndex] = peak;
                _waveformBarsReady = barIndex + 1;
                Invalidate(_waveformBounds);
            }));
        } catch { }
    }
    ```
  - IMPORTANT: Do NOT invoke on every single bar -- that would be ~2000 Invoke calls. Instead, batch the progressive reveal: only invoke every ~50 bars (or use a time-based throttle -- invoke at most every 100ms). Store bars in a local list and copy the batch on invoke.
  - After Generate returns successfully: write to cache `WaveformCache.WriteCache(key, peaks)`. Then invoke on UI to finalize: `_waveformPeaks = peaks; _waveformBarsReady = peaks.Length; Invalidate(_waveformBounds);`
  - If Generate returns null (cancelled or failed): on UI thread, if generationId still matches, set `_waveformUnavailable = true` only if NOT cancelled. Invalidate.

**Helper method for waveform X-to-time ratio:**
Add a private helper in PreviewWindow:
```csharp
private double GetWaveformTimeRatio(Point point)
{
    int padding = (int)(8 * (CreateGraphics().DpiX / 96.0f));
    int waveformLeft = _waveformBounds.Left + padding;
    int waveformRight = _waveformBounds.Right - padding;
    int waveformWidth = waveformRight - waveformLeft;
    if (waveformWidth <= 0) return 0;
    double ratio = (double)(point.X - waveformLeft) / waveformWidth;
    return Math.Max(0, Math.Min(1, ratio));
}
```

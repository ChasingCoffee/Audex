  <action>
    **AppConfig.cs** -- Add new properties with defaults:
    - `Autoplay` (bool, default false) -- PLAY-04: off by default for first-time users
    - `AutoplayDelayMs` (int, default 500) -- 500ms delay per user decision
    - `Loop` (bool, default false) -- loop toggle state
    - `WasapiDeviceIndex` (int, default -1) -- -1 = system default WASAPI device
    - `WaveformHeightPreset` (string, default "Medium") -- "Small", "Medium", "Large"

    **PathHelper.cs** -- Add `GetJsonConfigPath()` returning `%LOCALAPPDATA%\Audex\config.json`.

    **Audex.csproj** -- Add `System.Text.Json` NuGet package reference for .NET Framework 4.8 JSON serialization. This is the modern Microsoft serializer. If it causes issues with net48 targeting, fall back to `Newtonsoft.Json` instead.

    **ConfigManager.cs** -- Complete rewrite of Load/Save to use JSON:
    1. Add a private static method `MigrateIfNeeded()` that checks if `config.ini` exists and `config.json` does not. If so, load the INI using the existing ini-parser logic (keep as a private migration method), map all fields to AppConfig, serialize to JSON, write to `config.json`. Leave `config.ini` in place as backup (do NOT delete).
    2. `Load()`: Call `MigrateIfNeeded()` first. Then read `config.json` via `System.Text.Json.JsonSerializer.Deserialize<AppConfig>()`. Use `JsonSerializerOptions { PropertyNameCaseInsensitive = true, WriteIndented = true }`. If file doesn't exist, return `new AppConfig()` (defaults). Wrap in try/catch, fall back to defaults on error.
    3. `Save(AppConfig)`: Serialize to JSON with `WriteIndented = true`, write to `config.json` path. Ensure directory exists first.
    4. Keep `GetExtensions()` as-is (calls Load() internally).
    5. The `ini-parser-netstandard` package reference should remain in csproj for the migration path. It can be removed in a future cleanup phase.

    Use `System.Globalization.CultureInfo.InvariantCulture` is not needed for JSON serializer (it handles floats correctly). Ensure Volume is clamped to 0.0-1.0 on load.
  </action>
  <verify>
    `dotnet build src/Audex -c Release` succeeds. Manually verify: if a config.ini exists in %LOCALAPPDATA%\Audex, running ConfigManager.Load() should produce a config.json alongside it with all migrated values. New AppConfig fields should have correct defaults.
  </verify>
  <done>
    ConfigManager reads/writes JSON at config.json path. INI migration runs once on first load if config.ini exists. AppConfig has all 5 new fields with correct defaults. Project builds cleanly.

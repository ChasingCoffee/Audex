    - Title "Settings" at top with X close button on right

    - Device dropdown items cached in a static list of rectangles.

    4. **OnMouseDown**: Check gear icon first. If `_settingsOpen`, check SettingsOverlayRenderer.HitTest():

       - FrequencyColorToggle -> toggle config.WaveformColorMode, save, update _isWaveformColorMode, Invalidate

       - AnalysisToggle -> toggle config.EnableBpmKeyDetection, save, Invalidate
       - ClearCacheButton -> call AnalysisCache.ClearAll() (add static method if not present), show brief confirmation
       - CheckUpdatesButton -> launch GitHub releases check in background thread (use WebClient/HttpClient to GET https://api.github.com/repos/OWNER/REPO/releases/latest, parse tag_name).        - ResetDefaultsButton -> create new AppConfig() with defaults, save via ConfigManager.Save(), reload all local state from defaults, Invalidate
       - Background (inside overlay) -> do nothing (prevent click-through)
       - If click is OUTSIDE overlay bounds AND outside gear icon -> CloseSettings()

    5. **OnMouseMove**: Update gear icon hover state. When overlay is open, update hover states for overlay controls.

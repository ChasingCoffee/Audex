  <action>
    Create `installer/Audex.iss` -- a complete Inno Setup 6.x script.

    **[Setup] section:**
    - AppName=Audex
    - AppVersion=1.0.0
    - AppPublisher=Audex
    - DefaultDirName={autopf}\Audex
    - PrivilegesRequired=admin
    - OutputBaseFilename=Audex-Setup
    - Compression=lzma2/ultra64
    - SolidCompression=yes
    - DisableProgramGroupPage=yes (no Start Menu entry per user decision)
    - LicenseFile= (omit -- no license agreement page per user decision; include license.txt in files)
    - UninstallDisplayIcon={app}\Audex.dll
    - ArchitecturesAllowed=x64compatible
    - ArchitecturesInstallIn64BitMode=x64compatible
    - WizardStyle=modern

    **[Files] section:**
    Bundle ALL files from the Release output directory:
    - Audex.dll (main assembly)
    - bass.dll, basswasapi.dll, bassflac.dll, bassmix.dll, bass_fx.dll (core BASS)
    - bass_aac.dll, basswma.dll, bassopus.dll (plugin DLLs)
    - All managed dependency DLLs (Serilog, ini-parser, ManagedBass, TagLibSharp, System.Text.Json and its deps)
    - Source path: `..\src\Audex\bin\x64\Release\net48\*` (all files)
    - DestDir: {app}
    - Flags: ignoreversion

    **[Components] section:**
    Use components for file type registration checkboxes:
    - "core": Description "Core audio formats (.wav, .mp3, .flac, .aiff, .aif, .ogg)"; Types: full custom; Flags: fixed (always installed)
    - "module": Description "Module formats (.mod, .xm, .it, .s3m)"; Types: full custom
    - "aac": Description "AAC/M4A formats (.aac, .m4a)"; Types: full custom
    - "wma": Description "WMA format (.wma)"; Types: full custom
    - "opus": Description "Opus format (.opus)"; Types: full custom

    **[Types] section:**
    - Name: "full"; Description: "All supported formats"
    - Name: "custom"; Description: "Custom selection"; Flags: iscustom

    **[Code] section (Pascal scripting):**

    1. `function InitializeSetup(): Boolean;`
       - Check .NET 4.8: query `HKLM\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full` Release DWORD. If < 528040, show message "This application requires .NET Framework 4.8 or later. Please download it from: https://dotnet.microsoft.com/download/dotnet-framework/net48" and return False.
       - Return True otherwise.

    2. `function PrepareToInstall(var NeedsRestart: Boolean): String;`
       - Check if prevhost.exe is running using `FindWindowByClassName` or `Exec('tasklist', ...)` parsing. Simplest: use `Exec(ExpandConstant('{sys}\tasklist.exe'), '/fi "IMAGENAME eq prevhost.exe" /nh', ...)` and check output. Or use the `ProcessExists` helper pattern.
       - If running, show MsgBox: "Windows Preview Host (prevhost.exe) is currently running and must be stopped to update the preview handler. Stop it now?" (Yes/No).
       - If Yes: `Exec(ExpandConstant('{sys}\taskkill.exe'), '/f /im prevhost.exe', '', SW_HIDE, ewWaitUntilTerminated, ResultCode)`, then Sleep(500).
       - If No: Return 'Installation cancelled. Please close any open preview panes and try again.'.
       - Return '' (empty = proceed).

    3. `procedure CurStepChanged(CurStep: TSetupStep);`
       At `ssPostInstall`:
       - Determine regasm path dynamically: read `HKLM\SOFTWARE\Microsoft\.NETFramework\InstallRoot` for .NET install root, append `v4.0.30319\RegAsm.exe`. Fallback to `{win}\Microsoft.NET\Framework64\v4.0.30319\RegAsm.exe`.
       - Run regasm: `Exec(RegAsmPath, '"' + ExpandConstant('{app}\Audex.dll') + '" /codebase', ExpandConstant('{app}'), SW_HIDE, ewWaitUntilTerminated, ResultCode)`.
       - Read the CLSID from a constant (matching ComGuids.cs: `{F2A5B8C3-4D7E-4A9B-8C1F-3E6D5A7B9C2E}`).
       - Set CLSID registry entries (mirrors register.ps1):
         * `HKCR\CLSID\{CLSID}` DisplayName = "Audex"
         * `HKCR\CLSID\{CLSID}` AppID = "{6d2b5079-2f0b-48dd-ab7f-97cec514d30b}"
         * `HKCR\CLSID\{CLSID}` DisableLowILProcessIsolation DWORD = 1
         * `HKCR\CLSID\{CLSID}\InprocServer32` ThreadingModel = "Apartment"
       - Register in PreviewHandlers list: `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\PreviewHandlers` -> CLSID = "Audex"
       - Register file type associations based on selected components:
         * Core (always): .wav, .mp3, .flac, .aiff, .aif, .ogg
         * Module (if selected): .mod, .xm, .it, .s3m
         * AAC (if selected): .aac, .m4a
         * WMA (if selected): .wma
         * Opus (if selected): .opus
       - For each extension: write to `HKCR\SystemFileAssociations\{ext}\shellex\{IPreviewHandler IID}` default = CLSID. Also check for ProgID and register under `HKCR\{ProgID}\shellex\{IPreviewHandler IID}`. Do NOT modify UserChoice/AppX ProgIds (per project lesson).
       - The IPreviewHandler IID is `{8895b1c6-b41f-4c1c-a562-0d564250836f}`.
       - Use `WizardIsComponentSelected('core')`, `WizardIsComponentSelected('module')`, etc. to check user's selection.

    4. `procedure CurUninstallStepChanged(CurUninstallStep: TUninstallStep);`
       At `usPostUninstall`:
       - Run regasm /unregister.
       - Remove CLSID registry key.
       - Remove from PreviewHandlers list.
       - Remove all file association registry entries (iterate all extensions).
       - If user selected "Remove settings and cache": delete `%LOCALAPPDATA%\Audex\` directory and `%TEMP%\Audex\` directory.

    5. For the "Remove settings and cache" checkbox on uninstall, use `[UninstallDelete]` section with conditional checks, or add a custom uninstall page. Simplest: In `CurUninstallStepChanged(usUninstall)`, show a MsgBox asking "Remove settings and cache data?" before cleanup.

    6. Explorer restart prompt: After post-install, show a MsgBox: "Installation complete! Would you like to restart Windows Explorer now to activate the preview handler?" If Yes, kill and restart explorer.exe: `Exec('{sys}\taskkill.exe', '/f /im explorer.exe', ...)` then `Exec('{win}\explorer.exe', '', ...)`.

    **Do NOT include:**
    - License agreement page (LicenseFile omitted)
    - Start Menu entries
    - Silent/unattended install support
    - Background update checking

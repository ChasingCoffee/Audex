  <action>
    **AudioPreviewHandler.cs** -- Rewrite `TranslateAccelerator(ref MSG pmsg)`:

    1. Add `GetKeyState` P/Invoke to the NativeMethods inner class:
       ```
       [DllImport("user32.dll")]
       public static extern short GetKeyState(int nVirtKey);
       ```

    2. Define constants at class level:
       ```
       private const uint WM_KEYDOWN = 0x0100;
       private const uint WM_SYSKEYDOWN = 0x0104;
       private const int VK_CONTROL = 0x11;
       ```

    3. In TranslateAccelerator, check for WM_KEYDOWN or WM_SYSKEYDOWN. Extract the virtual key from pmsg.wParam. Check Ctrl state via `(NativeMethods.GetKeyState(VK_CONTROL) & 0x8000) != 0`.

    4. If Ctrl is held, switch on virtual key code:
       - Keys.Space (0x20) -> `InvokeOnUI(() => _previewWindow.TogglePlayPause())` -> return S_OK
       - Keys.Left (0x25) -> `InvokeOnUI(() => _previewWindow.SeekRelative(-5.0))` -> return S_OK
       - Keys.Right (0x27) -> `InvokeOnUI(() => _previewWindow.SeekRelative(5.0))` -> return S_OK
       - Keys.Up (0x26) -> `InvokeOnUI(() => _previewWindow.AdjustVolume(0.05f))` -> return S_OK
       - Keys.Down (0x28) -> `InvokeOnUI(() => _previewWindow.AdjustVolume(-0.05f))` -> return S_OK
       - Keys.L (0x4C) -> `InvokeOnUI(() => _previewWindow.ToggleLoop())` -> return S_OK
       - Keys.M (0x4D) -> `InvokeOnUI(() => _previewWindow.ToggleMute())` -> return S_OK
       - Keys.OemComma (0xBC) -> `InvokeOnUI(() => _previewWindow.ToggleSettings())` -> return S_OK

    5. Without Ctrl modifier, handle Escape key (0x1B):
       - If `_previewWindow.IsSettingsOpen` -> `InvokeOnUI(() => _previewWindow.CloseSettings())` -> return S_OK

    6. For any unhandled key, forward to `_frame.TranslateAccelerator(ref pmsg)` if frame is available, otherwise return S_FALSE.

    7. Wrap the entire method body in try/catch, returning S_FALSE on error (consistent with existing pattern).

    **PreviewWindow.cs** -- Add/verify public methods (some may already exist from plan 01/02):

    1. `TogglePlayPause()`: If playing, pause. If paused/stopped, play. Call `_player.Play()` or `_player.Pause()`. Start/stop position timer. Invalidate.

    2. `SeekRelative(double seconds)`: Get current position from `_player.CurrentPositionSeconds`, add `seconds`, clamp to [0, duration], call `_player.Seek(newPosition)`. Invalidate waveform.

    3. `AdjustVolume(float delta)`: Add delta to `_volume`, clamp to [0.0, 1.0]. If adjusting from muted state, unmute first. Call `_player.SetVolume(_isMuted ? 0f : _volume)`. Persist to config. Invalidate control bar.

    4. `ToggleMute()`: Flip `_isMuted`. Call `_player.SetMute(_isMuted)` and `_player.SetVolume(_isMuted ? 0f : _volume)`. Persist to config. Invalidate control bar.

    5. Verify `ToggleLoop()`, `ToggleSettings()`, `CloseSettings()`, `IsSettingsOpen` exist from plans 01/02. If any are missing, add them.

    Keyboard shortcuts are active when the preview pane has focus. This is the standard behavior for Shell preview handlers using TranslateAccelerator -- Explorer routes keystrokes to the active preview handler's TranslateAccelerator when its pane is focused. Do NOT use global keyboard hooks or any non-standard mechanism.

# Requirements: Audex

**Defined:** 2026-02-16
**Core Value:** Select an audio file in Windows Explorer and immediately hear and see it — waveform, playback, metadata — without opening another application.

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Preview Handler

- [x] **PREV-01**: Preview pane appears in Windows Explorer when audio file selected
- [x] **PREV-02**: Preview updates when user selects a different audio file
- [x] **PREV-03**: Audio file is released (not locked) when preview closes or file changes
- [x] **PREV-04**: Errors are logged to AppData for debugging
- [x] **PREV-05**: Handler runs correctly in low-integrity process

### Playback

- [x] **PLAY-01**: User can play, pause, and stop audio playback
- [x] **PLAY-02**: User can seek to any position via timeline scrub
- [x] **PLAY-03**: User can adjust volume independently of system volume
- [x] **PLAY-04**: User can toggle autoplay (auto-play on file select)
- [x] **PLAY-05**: User can control playback via keyboard (space=play/pause, arrows=seek)

### Waveform

- [x] **WAVE-01**: Waveform visualization displays when file is loaded
- [x] **WAVE-02**: Waveform is colored by frequency content (bass/mids/highs)
- [x] **WAVE-03**: User can click on waveform to seek to that position
- [x] **WAVE-04**: Playback position indicator moves across waveform during playback

### Format Support

- [x] **FMT-01**: Supports WAV, MP3, and FLAC playback
- [x] **FMT-02**: Supports AIFF, OGG, AAC, WMA, OPUS, and M4A playback
- [x] **FMT-03**: Supports module formats (.mod, .xm, .it, .s3m)
- [x] **FMT-04**: Unsupported formats show clear error message (not crash)

### Metadata

- [x] **META-01**: Displays duration, sample rate, bit depth, and channel count
- [x] **META-02**: Displays title, artist, and album from ID3/Vorbis tags
- [x] **META-03**: Displays BPM and musical key from existing tags
- [x] **META-04**: Detects BPM via audio analysis when tag is missing
- [x] **META-05**: Detects musical key via audio analysis when tag is missing
- [x] **META-06**: Caches analysis results to avoid re-analyzing files

### Configuration

- [x] **CONF-01**: Settings stored in JSON config file in AppData
- [x] **CONF-02**: User can select audio output device (WASAPI default, optional ASIO)
- [x] **CONF-03**: User can toggle autoplay on/off
- [x] **CONF-04**: Settings UI accessible from the preview pane

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Enhanced Playback

- **PLAY-06**: User can adjust playback speed without pitch shift
- **PLAY-07**: User can set loop region for repeated playback
- **PLAY-08**: User can set A-B repeat points

### Advanced Visualization

- **WAVE-05**: User can zoom into waveform for detailed view
- **WAVE-06**: User can set and view cue point markers on waveform

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Album art display | Explorer already shows thumbnails, not needed for audio preview |
| Video file support | Different rendering pipeline, massive complexity increase |
| Audio editing / effects | Preview handler is read-only by design |
| Tag editing / writing | Write operations complicate shell extension, file locking concerns |
| Playlist / multi-file queue | Violates single-file IPreviewHandler contract |
| Streaming / URL support | Shell extension targets local filesystem only |
| Plugin system | Stability risk for shell extension running inside Explorer |
| Batch processing | Preview handler is single file focus, separate tool if needed |

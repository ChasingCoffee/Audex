### Minor Integration Observations (non-blocking)

1. **DisableLowILProcessIsolation not in ComRegisterFunction** — `PreviewHandlerRegistration.Register()` does not write this registry value. Only affects the unsupported `regasm`-only deployment path (installer and register.ps1 both set it). Not a gap for any documented deployment method.

2. **ManagedBass.Flac.dll dead weight** — Managed wrapper shipped but never `using`-imported. FLAC works via native `bassflac.dll` auto-loaded by BASS. Adds ~50KB to installer payload with no benefit.
